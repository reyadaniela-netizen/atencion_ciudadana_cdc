# Atención Ciudadana Carmen - AI Copilot

Solución para clasificación y priorización de reportes urbanos en Ciudad del Carmen.

## Modelo Utilizado
* **Modelo:** Gemma 4 26B A4B IT (`gemma-4-26b-a4b-it`) vía Gemini API.
* **Términos de uso / Licencia:** [Gemma Terms of Use](https://ai.google.dev/gemma/terms)

## Integración
Inferencia en la nube mediante `google-genai` configurada con Google AI Studio.
